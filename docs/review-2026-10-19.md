# Logica-review 2026-10-19

Onafhankelijke doorloop van de hele pipeline (model → EV → koopprijs → alerts → paper-portfolio), gevraagd vóór de
eerste echte inkopen (na de review van 1 november) en vóór Naruto. Bevindingen en wat ermee gedaan is.

## Gefixt (PR #43)

| # | Bevinding | Fix |
|---|---|---|

## Gecontroleerd en in orde
EV-berekening per set (handmatig nagerekend voor FB10, FB11, BT30, BT28: exact), pagina = Python (max €0,02 verschil),
Cardmarket-koppeling kiest in alle 178 dubbel-gelijste gevallen het Engelse product, SAA/GDR buiten de ratio, geen
crashpad voor Naruto (score uit → geen sets; retail op titel; news op regex).

## Open, bewust
- Masters pull-rates blijven aannames tot de review van 1 november.
- Cardmarket-prijsgids mengt talen: bij Fusion World geen probleem (aparte Non-English-expansie), bij Masters is de box
  alleen indicatie. Kaartprijzen van Masters kunnen nog JP/FR-verkopen bevatten → EV eerder te laag dan te hoog.
- Verzendkosten zijn vaste opslagen (box €18, kaart €5); een echte per-verkoper-prijs vereist de Cardmarket-API.
- Naruto: eerste boosterbox geeft een 📰/nieuw-product-bericht via retail en news; de 📦-melding op sets volgt zodra de set bestaat.
